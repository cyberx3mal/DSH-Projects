# DSH-Projects — виджет для DeepSeek Harness

Русский | [English](README.en.md)

Компактный постоянно видимый виджет проектов в левой панели [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): все проекты, их чаты и живой статус — не открывая отдельную страницу. Бандл добавляет один слот `sidebar.footer.action` и раздел **«Проекты»** в настройках Harness; в верхнее меню и на отдельную страницу он ничего не добавляет.

## Что здесь есть

Корень репозитория — сам бандл: `package.json`, `client.js`, `index.js`, `cordis.patch.yml`, `locale/`, `icon.svg`. Рядом лежат `README.en.md` (English) и `verify.mjs` — автономная проверка браузерной половины.

## Возможности

### Компактный виджет в левой панели

Виджет стоит в подвале боковой панели, над «Ещё», и виден без открытия чего-либо.

- **Каждый проект** со своими чатами; список прокручивается, хвост не прячется.
- **Пять визуальных состояний чата**: работают — жёлтый; ждут разрешения / план / ответа — синий; завершено, но не прочитано — зелёный; ошибка — красный; завершено и прочитано — серый.
- **Непрочитанное завершение**: у чата — зелёная точка, зелёный цвет времени и жирный заголовок; у проекта — один зелёный счётчик непрочитанных. Слово «новое» не повторяется в каждой строке. После прочтения флаг снимается, чат становится серым.
- **Ошибка**: красная точка, красный счётчик у проекта и подпись «ошибка». Если хост не отдаёт `failed`/`error`, красное состояние не появится — данных об ошибке просто нет.
- **Фильтры видимости**: отдельные счётчики для ожидания, работы, непрочитанных, ошибок и прочитанных. Клик скрывает/показывает только этот статус; «Все» возвращает все пять. Нулевые счётчики не занимают место в шапке. Выбор переживает reload.
- **Баннер разрешения**: если чат ждёт approval, над списком появляется синий баннер. В первой строке — рабочее пространство, во второй — чат и инструмент; кнопки **«Разрешить один раз»** и **«Отклонить»** отвечают, не открывая сессию. «Всегда разрешать» остаётся в чате. Баннер можно отключить в настройках.
- **Развернуть/свернуть все**: кнопка справа от «Все» раскрывает или сворачивает все строки проектов; в свёрнутой полоске скрыта.
- **Раскрываемые проекты**: шеврон показывает чаты проекта; клик по названию открывает самый свежий активный чат.
- **Аккордеон**: открытие нейтрального проекта сворачивает остальные нейтральные; проекты, раскрытые шевроном, остаются открытыми. Проекты с ожиданием, непрочитанными или ошибкой остаются развёрнутыми, чтобы их было видно. Поведение отключается в настройках.
- **Активный проект**: проект чата, открытого в основной области, подсвечен; текущий чат выделен в списке.
- **Одна строка**: клик по «Проекты» сворачивает виджет в полоску со счётчиками; повторный клик возвращает прежнее состояние (видимость статусов, раскрытые строки, сортировку). Состояние переживает reload.
- **Сортировка**: кнопка открывает меню — сначала активные, по активности, по названию, по числу чатов. Выбор запоминается.
- **Быстрый переход**: клик по чату открывает его.
- Русский и английский, тёмная и светлая темы на токенах хоста.

## Настройки

В настройках Harness появляется раздел **«Проекты»** (`settings.section` с иконкой). Все строки применяются сразу:

| Настройка | Значения | По умолчанию |
|---|---|---|
| Сортировка | сначала активные / по активности / по названию / по числу чатов | сначала активные |
| Счётчики | проекты / чаты | проекты |
| Видимые статусы | ждут / работают / непрочитанные / ошибки / прочитанные | все включены |
| Держать ждущие развёрнутыми | вкл / выкл | вкл |
| Держать непрочитанные развёрнутыми | вкл / выкл | вкл |
| Только активный нейтральный проект | вкл / выкл | вкл |
| Счётчик непрочитанных | вкл / выкл | вкл |
| Разрешать из виджета | вкл / выкл | вкл |

**Только активный нейтральный проект** — аккордеон для нейтральных проектов: клик по названию открывает проект и сворачивает остальные нейтральные; проект, раскрытый шевроном, остаётся открытым. Проекты с ожиданием (синий), непрочитанными (зелёный) и ошибкой (красный) не сворачиваются при переключении и остаются видимыми, пока их не свернуть стрелочкой или не выключить соответствующие настройки.

Счётчики и настройки используют одно хранилище, поэтому изменения применяются к виджету сразу. **«Сбросить настройки»** возвращает сортировку «сначала активные», все статусы, авто-раскрытие, аккордеон и бейдж, а также разворачивает виджет.

## Установка

Плагин — обычный DSH-бандл, устанавливается из локального каталога:

```text
plugin_manager install_bundle { "target": "<absolute-path-to-this-repo>" }
```

`plugin_manager` — встроенный менеджер бандлов DSH (инструмент агента и тот же сервис за страницей **Plugins**), а не зависимость плагина. Если инструмента нет, используйте **Plugins → Add plugin** и выберите локальный каталог пакета. Бандл привязывается к активному профилю и включается; страница подхватывает его после перезагрузки. Удалить — на странице **Plugins** (или через `plugin_manager`).

Штатная панель не заменяется: виджет регистрируется в аддитивном слоте `sidebar.footer.action`. Он не регистрирует `sidebar.panellist` и `main`, поэтому верхнее меню и браузер сессий остаются нетронутыми.

## Данные и состояние

- Читает проекции Client Session и Workspace (`ctx.sessions.list`, `ctx.workspaces.list`) и хук статуса сессии — без polling.
- Пользовательские настройки живут в `localStorage`: `projects-board:sort`, `projects-board:collapsed`, `projects-board:visible` и `projects-board:settings` (счётчики, авто-раскрытие, аккордеон, счётчик непрочитанных, разрешения из виджета).
- Виджет скрывается в рельсе, когда проектов нет или панель не `wide`.
- Видимость статусов применяется при построении списка: скрытые состояния исчезают из проектов и раскрытых чатов; счётчики сохраняют свои итоги (проекты или чаты — по настройке), чтобы скрытые статусы оставались заметными.

## Разработка

```bash
node verify.mjs
```

Тест загружает `client.js` с фейковым Module Loader и заглушкой React, монтирует плагин против фейковых Client-сервисов и проверяет регистрации виджета и настроек, статусы и цвета, непрочитанное завершение, фильтры, сортировку, аккордеон, сворачивание, навигацию, сохранение состояния и пустые состояния.

Плагин — обычный JavaScript: `index.js` — пустая Host-половина, `client.js` — вся браузерная часть, `locale/*.json` — метаданные для менеджера плагинов, `icon.svg` — иконка.
